# Launch demo (v2)

`LaunchDemo` (16:9) and `LaunchDemoVertical` (9:16).

- **Studio footage** is a real recording of Remotion Studio (`ChartStudio` composition) made with Playwright
  while `npx magichour-remotion dev` generated the Origami style live. The cursor is redrawn from the click
  log in `../demo-events.json`. The recording (`public/demo/studio.mp4`, 35 MB) is not committed.
- **Soundtrack** is generated with `<MagicMusic>`; sound effects are CC0 (Kenney, via soundcn).
- **Fonts**: Instrument Serif, Space Grotesk, JetBrains Mono (SIL OFL, from Fontsource).
